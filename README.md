# 🎬 Locadora de Filmes

Sistema desenvolvido em Java para gerenciamento de uma locadora de filmes, utilizando operações de CRUD e conceitos de Programação Orientada a Objetos (POO).

## 🎯 Objetivo

O projeto tem como objetivo praticar o desenvolvimento de um sistema de gerenciamento utilizando Java, aplicando conceitos de POO e operações de CRUD.

## 🚀 Funcionalidades

* Cadastrar filmes
* Listar filmes
* Buscar filmes
* Atualizar informações
* Remover filmes

## 🛠️ Tecnologias

* Java
* Programação Orientada a Objetos (POO)
* CRUD
* Git
* GitHub

## 📚 Conceitos aplicados

* Classes e objetos
* Atributos e métodos
* Encapsulamento
* Construtores
* Estruturas de controle
* Coleções
* Operações de CRUD
* Organização do código

## 📌 Sobre o projeto

Projeto desenvolvido para prática dos fundamentos da linguagem Java e dos conceitos de Programação Orientada a Objetos.

O projeto faz parte do processo de aprendizado e evolução em desenvolvimento de software.
